# Virtual Tour Architecture

Demo base para recorridos virtuales arquitectónicos con portada panorámica, navegación por plantas, selección de ambientes y vistas 360°.

## Demo inicial

- Landing básica en `/`
- Demo `Casa Loja` en `/projects/casa-loja/`

## Objetivo

Usar esta plantilla como producto reutilizable para estudios arquitectónicos, empezando con una demo funcional que luego pueda adaptarse por branding y configuración.
